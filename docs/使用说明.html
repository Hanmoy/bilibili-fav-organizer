B站收藏整理台

B站收藏夹自动分类 + AI 辅助整理的工作台插件

油猴脚本 · 数据本地 · 风控保护

这是什么？

收藏了一堆视频却「收藏即吃灰」？本插件在 B 站页面右下角注入一个整理面板，一键抓取收藏夹全部视频，用「规则 + AI」自动分类，预览确认后把视频移入对应的分类收藏夹。

  • 规则优先：关键词/正则规则先行命中，结果确定、可离线、可编辑
  • AI 辅助：OpenAI 兼容接口（DeepSeek / 通义 / Kimi 等），只处理规则漏掉的视频
  • 启发式兜底：即使 AI 不可用，也按标题高频词归类，绝不整批丢进「未分类」
  • 风控保护：内置请求节流、指数退避、412 风控检测与分级冷却

安装方法（3 步）

1
安装脚本管理器

浏览器安装 Tampermonkey（篡改猴）或 Violentmonkey（暴力猴）扩展，并保持启用。

2
安装本脚本

将 bilibili-fav-organizer.user.js 文件拖入浏览器窗口，或复制文件内容新建脚本粘贴保存。Tampermonkey 会弹出安装确认，点「安装」即可。

3
打开 B 站使用

打开 bilibili.com 任意页面，右下角出现粉色「✦」按钮，点击展开工作台面板。

✅ 首次使用：先到「设置」填入 AI 配置（API 地址 + Key + 模型），保存并「测试连接」；不配置也能用（规则 + 启发式兜底）。

使用流程

  1. 收藏夹总览 → 点击某个收藏夹的「整理」按钮
  2. 智能整理 → 点「抓取全部视频」，等待进度完成
  3. 查看分类预览（可点击分类标题折叠/展开明细）
  4. 确认无误 → 点「确认并移动全部视频」
  5. 插件自动复用已有收藏夹，必要时新建分类收藏夹，逐分类限速移动
  6. 完成后刷新页面即可看到整理结果
⚠️ 移动是写操作：会真实改变你的收藏夹结构。请先在小收藏夹上试用，确认分类效果后再整理大收藏夹。若触发风控，插件会自动停止并提示冷却时间（IP 级约 10 分钟 / 账号级约 1 小时）。

数据与隐私

  • 全部数据保存在你的浏览器本地（GM 存储），不经过任何服务器
  • AI 请求仅向你自己配置的 API 地址发送视频标题等元信息，Key 仅存本机
  • 面板「设置」页提供导出 JSON 备份 / 导入恢复，建议定期导出
  • 整理记录最多保留最近 200 条，防止存储无限膨胀
